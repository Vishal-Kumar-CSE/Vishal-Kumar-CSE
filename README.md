## 🚀 Featured Project

### 🌍 Wanderlust — Cloud-Native DevSecOps Platform

A production-style DevSecOps project demonstrating the complete application delivery lifecycle on Kubernetes.

**Architecture & Tools**

```text
Developer
    │
    ▼
   Git
    │
    ▼
CI/CD Pipeline
    │
    ├── Code Quality → SonarQube
    ├── Secret Scan → Gitleaks
    ├── Dependency Scan → OWASP
    ├── Container Scan → Trivy
    └── IaC Scan → Checkov
    │
    ▼
 Docker Image
    │
    ▼
 Docker Hub
    │
    ▼
  Argo CD
    │
    ▼
    AKS
    │
    ├── Ingress
    ├── cert-manager
    ├── Let's Encrypt
    └── Kubernetes Services
    │
    ▼
Prometheus + Grafana
```

**Key areas explored:**

* ☁️ Azure Kubernetes Service (AKS)
* 🏗️ Terraform infrastructure provisioning
* 🔄 CI/CD automation
* 🐳 Docker containerization
* ☸️ Kubernetes deployments
* 🔁 GitOps with Argo CD
* 🔐 DevSecOps security gates
* 🌐 NGINX Ingress
* 🔒 TLS certificates with cert-manager & Let's Encrypt
* 📊 Prometheus & Grafana monitoring
* 🧪 Load testing and application validation

👉 **Repository:** [Wanderlust-Mega-Project-AKS](https://github.com/)
